# ConversorMoneda
## Desafio Alura
**Conversor de monedas en Java** que utiliza la API de [ExchangeRate-API](https://www.exchangerate-api.com/) para realizar conversiones entre diferentes monedas de forma interactiva.

## 🚀 **Características del Proyecto**

- **Conversión de Monedas**: Realiza conversiones entre varias monedas utilizando las tasas de cambio en tiempo real.
- **Historial de Conversiones**: Guarda un historial de las conversiones realizadas con fecha y hora.
- **Interfaz de Consola**: Menú interactivo fácil de usar.
- **Múltiples Monedas Soportadas**: Actualmente soporta monedas como USD, ARS, BRL, COP, CLP, y más.
